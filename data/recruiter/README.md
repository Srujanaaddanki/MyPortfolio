# Recruiter Quick Access Content Management

This folder contains the configuration for the Recruiter Quick Access panel.

## Structure

- `quicklinks.json`: Contains the configuration for the 5 quick links cards.

## How to Manage Quick Links

### 1. Edit Card Labels/Descriptions
1. Open `quicklinks.json`.
2. Edit the `"title"`, `"description"`, or `"target"` fields.
3. For icon support, you can use any valid Lucide icon name (e.g. `FileText`, `FolderCode`, `Award`, `Trophy`, `Mail`).
4. Commit and push.
